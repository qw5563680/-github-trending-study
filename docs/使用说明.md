# 使用说明与常见问题

[← 回首页](../README.md)

## 一句话说明

这个仓库每周自动做两件事：**先把 GitHub 周榜“拍张照”存下来，再把榜首项目写成一篇中文大白话教程**。
你只需要每周打开仓库首页，点最上面的「阅读最新一期」。

## 每周会自动发生什么

| 时间（北京时间） | 谁在干活 | 做什么 | 需要你的电脑开机吗 |
|---|---|---|---|
| 周一 09:00 左右 | GitHub Actions（GitHub 自带的云端自动化） | 打开 [Trending 周榜](https://github.com/trending?since=weekly)，按页面顺序记下前几名、抓取时间、Star 数；保存榜首的官方 README、文档、发布说明；生成一期“教程待生成”的周报初稿 | 不需要 |
| 周一 10:10 左右 | Claude Code 云端定时任务（用你的 Claude 订阅） | 读保存下来的官方资料，按[写作规范](../WRITING_GUIDE.md)写榜首深度教程，自检通过后发布，首页的「阅读最新一期」随之更新 | 不需要 |

说明：

- GitHub 的定时任务不保证准点，可能晚几分钟到几十分钟。
- 两步是分开的：**GitHub Actions 不会、也不能调用你的 Claude 网页订阅**。写教程这一步由 Claude 自己的云端定时任务完成。
- 如果第二步没有跑（比如 Claude 订阅额度用完、GitHub 授权失效），周报会停在“教程待生成”，榜单和资料仍然保存着，不会丢。

## 首页上的几种状态是什么意思

- **👉 阅读最新一期**：最新一篇**已经写完并通过检查**的周报。
- **⏳ 本期正在整理**：这一周的榜单已保存，但教程还没写完。此时「阅读最新一期」仍指向上一期。
- **⚠️ 最近一次自动运行没有成功**：比如榜单页面打不开。原因会写在首页上，已有周报不会被改动，
  也不会用猜的榜单或别的排名来顶替。

## 周报一直显示“待生成”怎么办

1. 打开 <https://claude.ai/code>，新建一个会话（仓库选 `-github-trending-study`）。
2. 把那一期周报里灰色框中的那句话原样发过去（形如“请打开仓库……补全 weekly/2026-Wxx.md……”）。
3. 等它写完，刷新仓库首页即可。

## 想立刻手动跑一次

1. 打开仓库的 **Actions** 页面，左侧点 **每周周榜快照**。
2. 右侧点 **Run workflow** → 再点绿色的 **Run workflow**。
3. 一两分钟后刷新，能看到一条新的运行记录。同一周内重复运行**不会**生成重复周报。

## 怎么暂停或修改

- **暂停榜单抓取**：仓库 **Actions** 页面 → 左侧 **每周周榜快照** → 右上角 **···** → **Disable workflow**。
- **暂停/修改写作任务**：打开 <https://claude.ai/code/routines>（Claude 的“定时任务”页面），
  找到 **GitHub 热门项目学习周报·每周写作**，用页面顶部的开关暂停，或在名称旁的菜单里选 **Edit / Delete**。
- **改写作要求**：直接修改 [WRITING_GUIDE.md](../WRITING_GUIDE.md)，下周生效。

## 费用

- **GitHub Actions**：本仓库是公开仓库，使用 GitHub 提供的标准运行环境不收费（以 [GitHub 官方计费说明](https://docs.github.com/billing/managing-billing-for-github-actions/about-billing-for-github-actions)为准）。
  如果以后改成私有仓库，则使用每月的免费分钟数；本流程每周一次、每次约 1 分钟，远低于免费额度。
- **Claude 写作**：使用你现有 Claude 订阅的用量（官方说明：云端定时任务的运行计入账号用量和限额），**没有另外开通任何付费 API**。

### 备选方案（目前没有启用，也尚未验证）

如果以后想让“写教程”也完全在 GitHub Actions 里完成，官方提供
[Claude Code GitHub Action](https://code.claude.com/docs/en/github-actions)，有两种授权方式：

| 方式 | 怎么配置 | 费用 |
|---|---|---|
| 订阅令牌 | 在自己电脑上安装 Claude Code 后运行 `claude setup-token`，把得到的令牌存为仓库密钥 `CLAUDE_CODE_OAUTH_TOKEN` | 用订阅用量，不走 API 计费 |
| API 密钥 | 在 Claude 开发者平台创建 API 密钥，存为仓库密钥 `ANTHROPIC_API_KEY` | **按用量另外付费** |

仓库密钥的添加位置：仓库 **Settings → Secrets and variables → Actions → New repository secret**。
**不要把密钥或令牌粘贴到聊天里或提交到仓库文件中。** 这两种方式本仓库都没有接入，需要时再让 Claude Code 帮你加。

## 关于“周榜快照”

- 榜单以 GitHub Trending 的 **Repositories → This week → 全部编程语言** 为准，按页面显示顺序保留，展示前 5 名。
- 记录的是**抓取那一刻**页面上的内容。Trending 是滚动榜单，名次和数字随时在变，
  所以它不是“上一个自然周的最终排名”。
- **累计 Star**（项目至今的总数）和**本周新增 Star**（页面上的 “stars this week”）是两个数字，分开记录；页面上取不到就留空。
- 榜首和往期重复时，仍然如实写它是第 1 名，并链接到以前的入门教程；新一期只讲新变化或新案例。

## 仓库里都有什么

| 位置 | 内容 |
|---|---|
| `README.md` | 首页（自动生成） |
| `weekly/` | 每期周报，文件名是期号，如 `2026-W47.md` = 2026 年第 47 周 |
| `data/snapshots/<期号>/trending.json` | 当期榜单快照的原始记录 |
| `data/snapshots/<期号>/materials/` | 当期保存的官方资料（第三方项目原文副本，仅供写作参考） |
| `data/run-log.json` | 每次自动运行的时间、结果和原因 |
| `scripts/` | 自动流程的脚本（只用 Python 自带功能，不安装任何软件包） |
| `tests/` | 脚本的自检测试 |
| `.github/workflows/weekly.yml` | GitHub Actions 的定时配置 |
| `WRITING_GUIDE.md` | 写作规范 |

## 公开仓库须知

- 本仓库目前是**公开**的：周报、榜单快照和保存的官方资料，任何人都能看到。
- 想改成私有：仓库 **Settings** → 拉到最底部 **Danger Zone** → **Change repository visibility** → **Change to private**。自动流程不受影响。
- 想改仓库名：仓库 **Settings** → 最上面 **Repository name** → **Rename**。首页和周报里的链接会在下次自动运行时跟着更新；
  但 Claude 定时任务的指令里写着仓库名，改名后需要到 <https://claude.ai/code/routines> 把指令里的仓库名一起改掉（或让 Claude Code 帮你改）。
- `data/snapshots/*/materials/` 里是各项目官方文件的原样副本，版权归原项目所有，仅用于学习参考；来源链接和许可证见各目录下的 `source.json`、`repo.json`。

## 安全说明

- 自动流程只读取公开网页和公开接口，只往**本仓库**写文件，不需要任何额外密钥。
- 保存下来的官方资料是第三方内容，只作阅读；写作时不会在带有你账号凭据的环境里运行第三方项目的安装脚本。
- 教程里每一部分都会标注核实状态：**实际运行成功 / 依据官方文档整理 / 尚未验证**。
