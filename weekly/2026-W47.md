## 本周榜首深度教程：GoogleChrome/modern-web-guidance-src

<!-- gts:tutorial:start -->
> 先说明一点：这个仓库名字带 `-src`，是 **Modern Web Guidance** 的“源码仓库”（写指南、测效果的地方）。普通人真正用到的，是它发布出来的命令行小工具 `modern-web-guidance`。下面教的就是这个工具。

### 1. 它能做什么？

当你遇到“让 AI 帮我写网页，它却老是用好几年前的旧写法”这种情况，你可以把“这类功能现在该怎么写”这个问题交给它，得到一份由浏览器团队整理的、写给 AI 看的最新做法说明。

先解释几个词：

- **编程助手（coding agent）**：像 Claude Code、Codex 这类能替你写代码的 AI 工具。
- **技能（skill）**：给编程助手加装的一份“说明书”，告诉它遇到某类任务时该先做什么。
- **指南（guide）**：这个项目里一篇篇的短文，每篇只讲一件事，比如“弹窗怎么做出淡入淡出动画”。

官方的解释是：AI 学习用的资料里有大量旧代码，所以它常常写出又长又旧的写法，而浏览器其实早就自带了更省事的新功能。这个项目把新做法、容易踩的坑、旧浏览器上的备用方案整理成指南，让 AI 写网页前先查一下，再动手。按官方 README，它由 Chrome、Edge、Firefox 和 MDN（一个权威的网页技术文档站）团队与社区共同维护，目前覆盖 262 项较新的网页功能、204 个常见开发场景。

**适合谁**：正在用 AI 编程助手做网页、网站前端的人。

**哪些情况用不上**：

- 你不做网页，或者不用 AI 编程助手。
- 你做的是后台、数据库、服务器部署一类的事。官方在技能说明里明确写了这些不归它管。
- 你想找一个能点按钮的网页工具或聊天机器人。它没有图形界面，只是一个在命令行里用的查询工具，另外加一批可以在浏览器里直接阅读的指南文章。

### 2. 我怎么用？

这里只讲一条最容易成功的路：**先在浏览器里看指南长什么样（什么都不用装），再用两条命令亲手“搜索”和“取回”一篇指南**。这样你能亲眼看到 AI 平时是怎么用它的。

**开始前要准备：**

- 设备：一台 Windows 或 Mac 电脑，能上网。
- 账号：不需要注册任何账号。
- 费用：免费，不需要 API 密钥（相当于调用某个服务用的专属密码，这里用不到）。
- 软件：第 1 步只要浏览器。第 2 步起需要 Node.js 22 或更新的版本。Node.js 是一个让电脑能运行这类小工具的免费基础软件，装好后会附带一个叫 `npx` 的命令，作用是“临时下载并运行一个工具，不用正式安装”。
- 时间：第 1 步约 2 分钟。没装过 Node.js 的话，再准备约 10 分钟；命令试用本身约 5 分钟。

**第 1 步：在浏览器里先看一眼（不用装任何东西）**

- 在哪里操作：浏览器。打开[官方 README](https://github.com/GoogleChrome/modern-web-guidance-src/blob/6971ebbec2b127d57aaa24ba63bab7b9de9e656b/README.md)。
- 点击什么：往下滚到 **What's Included?** 这一节，找到一行带小三角的 **204 real-world developer use cases**，点一下把它展开。
- 成功后能看到：一份按类别排好的清单（accessibility、built-in-ai、css……），每条是一个蓝色链接加一句英文说明。点任意一条，比如 css 类别下的 **responsive-design**，就能读到那篇指南的原文。

这些指南就是工具“取回”给 AI 的内容。只想了解它是什么的话，看到这里就够了。

**第 2 步：打开终端**

终端是一个只用打字来指挥电脑的窗口。

- Windows：按 `Win` 键，输入 `PowerShell`，回车。
- Mac：按 `Command + 空格`，输入 `终端`（或 `Terminal`），回车。

成功后能看到：一个可以打字的窗口，里面有一个闪动的光标。

**第 3 步：检查有没有 Node.js**

在终端里输入下面这行，回车：

```shell
node -v
```

成功后能看到：一个以 `v` 开头的版本号。开头的数字是 22 或更大就可以。

如果提示找不到命令，或数字小于 22：打开 Node.js 官网 <https://nodejs.org/>，下载适合你电脑系统的安装包，一路按默认选项装好，然后**关掉终端再重新打开**，再执行一次上面的命令。官网页面上的具体按钮我没有逐一核对，请以页面实际显示为准。

**第 4 步：搜索指南**

输入下面这行，回车（搜索词必须用英文，这是工具的要求）：

```shell
npx modern-web-guidance@latest search "animate a dialog modal backdrop"
```

第一次运行时，可能会先问你是否同意下载这个工具，输入 `y` 回车即可。

成功后能看到：一个用方括号 `[ ]` 包起来的列表，最多 10 条，每条有两项内容——`id`（指南的编号名）和 `description`（一句英文说明）。

出处：[官方 README 的 Quickstart 部分](https://github.com/GoogleChrome/modern-web-guidance-src/blob/6971ebbec2b127d57aaa24ba63bab7b9de9e656b/README.md)。

> Windows 小提示：如果 PowerShell 报错说不能运行脚本，把命令开头的 `npx` 换成 `npx.cmd` 再试。这是官方技能说明里给 Windows 的写法。

**第 5 步：取回一篇指南**

把上一步看到的某个 `id` 填进下面的引号里。官方示例用的是这一个：

```shell
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"
```

成功后能看到：**多半不是文章本身，而是一两行以 `Output (` 开头的提示**，里面写着大小、行数、`saved to` 和一个文件位置。原因是：这个工具规定，内容超过 9.5 KB 就先存成文件，免得在窗口里显示不全；而这篇指南大约 10.7 KB，刚好超过。

接着把提示里的文件位置复制下来，用系统自带的记事本打开它：

- Windows（PowerShell 里执行，引号里换成你看到的位置）：

  ```shell
  notepad "这里粘贴 saved to 后面的文件位置"
  ```

- Mac（终端里执行）：

  ```shell
  open -e "这里粘贴 saved to 后面的文件位置"
  ```

打开后第一行是 `--- Guide for animate-to-from-top-layer ---`，下面是一篇英文文章。换成短一些的指南时，文章会直接显示在终端窗口里，开头同样是这一行。

**关于隐私**：官方 README 写明，这个工具会向 Google 发送匿名的使用信息，包括搜索词和取回的指南编号，但不收集你对 AI 说的原话。不想发送的话，可以先设置一个叫 `DISABLE_TELEMETRY=1` 的环境变量（相当于给电脑留一张“不要上报”的便条），再执行第 4、5 步。

- Mac 终端里先执行：

  ```shell
  export DISABLE_TELEMETRY=1
  ```

- Windows PowerShell 里先执行：

  ```shell
  $env:DISABLE_TELEMETRY = "1"
  ```

Mac 这一行是官方原文；Windows 这一行是 PowerShell 设置环境变量的通用写法，官方 README 没有单独给出。两种写法都只在当前这个终端窗口里有效。

**试过之后想正式装给自己的编程助手**：官方给的命令是下面这一行，它会启动一个一步步提问的安装向导。向导里的具体画面我没有运行过，这里不描述。用 Claude Code、Codex 等工具的专用装法，见官方 README 的 Alternative Installation Methods 一节。

```shell
npx modern-web-guidance@latest install
```

### 3. 带我完成一个小练习

**任务**：亲手查出“网页弹窗怎么做出平滑的出现和消失动画”的最新做法，并读懂查到的东西。

准备时间：没装 Node.js 约 10 分钟。练习时间：约 10 分钟。

**甲：先在网页上看一眼这篇指南（不用装任何东西）**

1. 用浏览器打开这篇指南的原文：<https://github.com/GoogleChrome/modern-web-guidance/blob/main/skills/modern-web-guidance/guides/ui-behaviors/animate-to-from-top-layer.md>
2. 你会看到一篇英文短文，标题是 “Animate Elements To and From Top Layer”。
3. 往下找这几个小标题：`Implementation`（怎么做）、`Example`（示例代码）、`Constraints & Accessibility`（限制和无障碍注意事项）、`Fallback strategies`（旧浏览器上的备用方案）。

标题和这几个小标题，我对照官方发布包里的同一篇文件核对过。这个网址指向的是最新版，以后内容可能会更新。

**乙：再用命令自己查一遍**

1. 按第 2 节的第 2、3 步打开终端并确认 Node.js 可用。
2. 执行搜索：

   ```shell
   npx modern-web-guidance@latest search "animate a dialog modal backdrop"
   ```

3. 按官方文档，应该会看到一个最多 10 条的列表。在里面找 `id` 是 `animate-to-from-top-layer` 的那一条，它的说明是 “Animate elements such as dialogs, popovers, and tooltips as they're entering/exiting the top layer.”，意思是“让弹窗、浮层、提示框在出现和消失时带动画”。
4. 执行取回：

   ```shell
   npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"
   ```

5. 按工具源码里的规则，应该会看到以 `Output (` 开头的提示和一个文件位置。照第 2 节第 5 步的办法用记事本打开那个文件。

**怎么判断成功了**：

- 搜索那一步输出的是带 `id` 和 `description` 的列表，而不是红色的报错。
- 取回那一步你最终读到了一篇文章，里面出现了 `@starting-style` 和 `allow-discrete` 这两个词。它们就是这篇指南教给 AI 的“新写法”的关键词。

**常见卡点**：

- 提示 `modern-web-guidance requires Node.js >= 22`：说明 Node.js 版本太旧，回到第 2 节第 3 步升级。
- 搜索结果是空的 `[]`：检查搜索词是不是英文。官方建议用 2 到 5 个英文单词描述一件事，比如 `light dismiss dialog`。
- 一直卡着不动：多半是网络问题，第一次运行需要联网下载这个工具。

乙部分我没有亲自运行。以上预期结果，是按官方文档整理、并对照官方发布包里的源码写的。

### 4. 它为什么能做到？

用“输入 → 处理 → 输出”三步来看：

- **输入**：AI 接到一个网页任务后，先把任务浓缩成几个英文词，比如“弹窗 动画”，交给这个工具。
- **处理**：工具在自己带的两百多篇指南里找最对口的。它同时用两种办法找：一种看“意思像不像”，一种看“关键词对不对得上”，再把两份排名合起来。查找这一步在你自己的电脑上完成，不用连到任何 AI 服务，也不需要密钥。
- **输出**：先给 AI 一份简短的候选清单，AI 挑中一篇后再取回全文。全文里有示例代码、容易踩的坑和旧浏览器的备用方案。AI 读完再写代码。

要分清两件事：“查找在本机完成”说的是搜索本身；工具默认还会另外向 Google 匿名上报搜索词，这一点见第 2 节的隐私说明。

**打个比方**：AI 像一位经验丰富、但手艺是几年前学的装修师傅。这个工具像一本放在工具箱里的“最新施工规范”小册子。师傅开工前先翻目录（搜索），找到对应那一页（取回），再照着新规范干活。

官方还做了一件值得注意的事：他们让 AI 分别在“带册子”和“不带册子”两种情况下做同一批网页任务，再用自动检查程序打分。官方 README 里 11 月 8 日的数据显示，三种主流编程助手的任务通过率从 54%～58% 提高到 82%～94%。这些是官方自己测的数字，我没有复现。

**最值得看的一个文件**：[`guides/modern-web-guidance/SKILL.md`](https://github.com/GoogleChrome/modern-web-guidance-src/blob/6971ebbec2b127d57aaa24ba63bab7b9de9e656b/guides/modern-web-guidance/SKILL.md)

这就是装给 AI 的那份“说明书”原文，不长，全是文字。看它能学到：怎样用大白话给 AI 定规矩——什么时候必须先查、搜索词该怎么写（它举了好例子和坏例子）、查不到时怎么办、哪些任务不要用它。你以后想给自己的 AI 写使用规则，这是一份很好的范本。

### 5. 学习判断

**判断：先收藏**

理由：

- **上手门槛**：在浏览器里读指南没有门槛。用命令试用只要两条命令，但前提是要装 Node.js、会开终端，查到的指南也全是英文，内容是写给 AI 和程序员看的。
- **费用**：免费，不需要账号和密钥。
- **对你有没有实际用处**：它的真正价值，是装进编程助手后让 AI 自动去查。如果你现在没有在用 AI 做网页，装了也用不上。等你哪天开始让 AI 帮你做网页，再回来把它装上，那时收益最大。
- **热度不等于必须学**：它这周排在榜首，说明很多做网页的人需要它，不代表每个人都要现在投入时间。

如果你今天就在用 Claude Code、Codex 这类工具做网页，可以直接动手，花 15 分钟做完第 3 节的练习。

**自测问题**：`search` 和 `retrieve` 这两个命令分别是做什么的，为什么 AI 要先用前一个、再用后一个？
